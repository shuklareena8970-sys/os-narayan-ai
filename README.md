# Narayana StudyOS AI

Welcome to the Narayana StudyOS AI application repository.

## How to Download the Debug APK

You can download the latest debug version of the application directly to your Android device from the GitHub Releases page:

1.  **Navigate to Releases:** Go to the [Releases](https://github.com/{{ github.repository }}/releases) page of this repository.
2.  **Find the Latest Release:** Look for the most recent release labeled with `debug-apk-build-X-Y`.
3.  **Download the APK:** In the "Assets" section of the release, click on the `.apk` file (e.g., `narayana-studyos-ai-debug-build-X.apk`) to download it.
4.  **Install:** Once downloaded, open the file on your Android device to install the application.

*Note: You may need to enable "Install from unknown sources" in your device settings to install this APK.*

Alternatively, if you are a contributor or prefer manual builds, you can find the APK artifact in the "Actions" tab of this repository under the latest successful build.
